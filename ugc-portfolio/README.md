# אתר תיק עבודות UGC

אתר של עמוד אחד ליוצרי תוכן UGC, בעברית (RTL), בסגנון של מגזין אופנה: רקע קרם, כותרות Bodoni עם הדגשות באיטליק, וסרטונים בתוך אייפונים בצבע נחושת. מותאם לנייד. כל האתר נמצא בקובץ אחד: `index.html`.

## מה יש באתר
1. פתיחה: השם, "UGC Creator", משפט מכירה, כפתורים, אינסטגרם ומייל, ותמונה בצורת קשת עם תג מסתובב "Available for collabs"
2. סרט נע עם התחומים שלך (Beauty, Fashion...)
3. About me: תמונת פולרויד, כמה שורות עליך, פרטים קצרים וחתימה
4. My works: שישה אייפונים עם ממשק בסגנון Reels
5. What I create: סוגי התוכן שאת/ה מצלם/ת
6. Brands, How we work (ארבעה שלבים) ו־Packages (שלוש חבילות)
7. Let's create something beautiful: פרטי קשר וכפתור וואטסאפ

## איך לערוך
- פתחו את `index.html` בעורך טקסט (למשל VS Code). כל מה שבסוגריים מרובעים, `Your Name`, `your_handle`, `you@example.com`, `050-000-0000` והמחירים `₪000` מחכים לפרטים שלכם.
- **השם בכותרת:** `<span class="en">Your</span><span class="en"><em>Name</em></span>`. מה שבתוך `<em>` יוצג באיטליק בצבע נחושת.
- **תמונה ראשית:** שמרו `me.png` ליד `index.html`. בתוך `<div class="arch">` החליפו את `<div class="hint">...</div>` בשורה `<img src="me.png" alt="השם שלך">`.
- **תמונת פולרויד:** שמרו `me2.jpg`. בתוך `<div class="shot">` החליפו את הטקסט בשורה `<img src="me2.jpg" alt="">`.
- **סרטונים:** שימו קבצי mp4 בתיקייה `videos/`. בכל אייפון החליפו את השורה `<div class="scene ..."></div>` בשורה:
  ```html
  <video src="videos/clip1.mp4" muted loop playsinline preload="metadata"></video>
  ```
  הכתוביות לדוגמה וכפתור ה־play נעלמים אוטומטית. הסרטון מתנגן בלי קול כשהוא מופיע במסך, ונגיעה בו מפעילה את הקול. כדאי לדחוס כל סרטון ל־5–10MB.
- **צבעים:** כל הצבעים מוגדרים בראש הקובץ, בתוך `:root`. למשל `--paper` לרקע ו־`--copper` לצבע הנחושת.
- **וואטסאפ וטלפון:** בקישורים `https://wa.me/972500000000` ו־`tel:+972500000000` רשמו את המספר בפורמט בינלאומי, בלי 0 בהתחלה.

## איך להעלות לאוויר בחינם
- **Netlify Drop:** גררו את התיקייה `ugc-portfolio` לאתר app.netlify.com/drop ותקבלו קישור מיד.
- **GitHub Pages:** בהגדרות הריפו, Settings ← Pages, בחרו את הענף ואת התיקייה.

את הקישור שתקבלו אפשר לשים ב"קישור בביו" באינסטגרם ובטיקטוק.
