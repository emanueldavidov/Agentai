# אתר תיק עבודות UGC

אתר של עמוד אחד ליוצרי תוכן UGC, בעברית (RTL), בסגנון אתרי Canva: רקע קרם, כותרות סריף באנגלית ומסגרות טלפון לסרטונים. מותאם לנייד. כל האתר נמצא בקובץ אחד: `index.html`.

## מה יש באתר
1. פתיחה: השם, "UGC Creator", אינסטגרם, אימייל וטלפון עם אייקונים, ותמונה שלך בלי רקע
2. About me: כמה שורות עליך
3. My works: סרטונים בתוך מסגרות טלפון בצבע נחושת
4. Brands: לוגואים של מותגים שעבדת איתם
5. Packages: שלוש חבילות מחירים
6. Let's work together: פרטי קשר וכפתור וואטסאפ

## איך לערוך
- פתחו את `index.html` בעורך טקסט (למשל VS Code) והחליפו כל טקסט בסוגריים מרובעים, כמו `[Your Name]` ו־`[השם שלך]`, ואת המחירים `₪000`.
- **תמונה:** הסירו רקע מהתמונה (למשל ב־remove.bg או ב־Canva), שמרו אותה בשם `me.png` ליד `index.html`, והחליפו את `<div class="placeholder">...</div>` בשורה `<img src="me.png" alt="השם שלך">`.
- **סרטונים:** שימו קבצי mp4 בתיקייה `videos/`. בכל טלפון החליפו את שורת `<span class="play" ...>` ואת שורת `<p class="sub">` בשורה:
  ```html
  <video src="videos/clip1.mp4" muted loop playsinline controls preload="metadata"></video>
  ```
  כדאי לדחוס את הסרטונים לפני ההעלאה (עד 5–10MB לסרטון).
- **צבעים:** כל הצבעים מוגדרים בראש הקובץ, בתוך `:root`. למשל `--cream` לרקע ו־`--copper` למסגרות הטלפונים.
- **וואטסאפ וטלפון:** בקישורים `https://wa.me/972500000000` ו־`tel:+972500000000` רשמו את המספר שלכם בפורמט בינלאומי, בלי 0 בהתחלה.

## איך להעלות לאוויר בחינם
- **Netlify Drop:** גררו את התיקייה `ugc-portfolio` לאתר app.netlify.com/drop ותקבלו קישור מיד.
- **GitHub Pages:** בהגדרות הריפו, Settings ← Pages, בחרו את הענף ואת התיקייה.

את הקישור שתקבלו אפשר לשים ב"קישור בביו" באינסטגרם ובטיקטוק.
