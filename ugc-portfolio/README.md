# אתר תיק עבודות UGC

אתר של עמוד אחד ליוצרי תוכן UGC, בעברית (RTL), מותאם לנייד ולמצב כהה. כל האתר נמצא בקובץ אחד: `index.html`.

## מה יש באתר
1. פתיחה: שם, משפט מכירה, פרטים קצרים ותמונה במסגרת של טלפון
2. למה UGC: הסבר קצר למותגים
3. תיק עבודות: 6 סרטונים אנכיים (9:16) עם סינון לפי תחום
4. תחומי תוכן ומותגים שעבדתם איתם
5. איך זה עובד: חמשת שלבי העבודה
6. חבילות ומחירים
7. יצירת קשר: אימייל, וואטסאפ, אינסטגרם וטיקטוק, עם כפתורי העתקה

## איך לערוך
- פתחו את `index.html` בעורך טקסט (למשל VS Code) והחליפו כל טקסט בסוגריים מרובעים, כמו `[השם שלך]` ו־`[מחיר]`.
- **סרטונים:** שימו קבצי mp4 בתיקייה `videos/`. בכל כרטיס סרטון החליפו את השורה
  `<span class="play" aria-hidden="true"></span>` בשורה:
  ```html
  <video src="videos/my-clip.mp4" muted loop playsinline controls preload="metadata"></video>
  ```
  כדאי לדחוס את הסרטונים לפני ההעלאה (עד 5–10MB לסרטון).
- **תמונת פרופיל:** שימו `me.jpg` ליד `index.html` והחליפו את ה־`div` עם `portrait-hint` בשורה `<img src="me.jpg" alt="השם שלך">`.
- **צבעים:** כל הצבעים מוגדרים בראש הקובץ, בתוך `:root` (למשל `--berry` לצבע הראשי).
- **וואטסאפ:** בקישור `https://wa.me/972500000000` רשמו את המספר שלכם בפורמט בינלאומי, בלי 0 בהתחלה.

## איך להעלות לאוויר בחינם
- **Netlify Drop:** גררו את התיקייה `ugc-portfolio` לאתר app.netlify.com/drop ותקבלו קישור מיד.
- **GitHub Pages:** בהגדרות הריפו, Settings ← Pages, בחרו את הענף ואת התיקייה.

את הקישור שתקבלו אפשר לשים ב"קישור בביו" באינסטגרם ובטיקטוק.
