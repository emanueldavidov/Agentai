# אתר תיק עבודות UGC

אתר של עמוד אחד ליוצרות ויוצרי תוכן UGC, בעברית, בסגנון מגזין אופנה בוורוד פודרה. את כל התוכן (טקסטים, תמונות, סרטונים ומחירים) עורכים מפאנל ניהול בכתובת `/admin`, בלי לגעת בקוד.

## מבנה התיקייה
| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html` | העיצוב. קורא את התוכן מהתיקייה `content/` |
| `content/*.json` | כל התוכן של האתר. נערך מפאנל הניהול |
| `uploads/` | תמונות וסרטונים שמועלים מפאנל הניהול |
| `admin/` | פאנל הניהול (Decap CMS) |
| `EDITING.md` | מדריך עריכה קצר למי שמנהלת את האתר |
| `../netlify.toml` | אומר ל־Netlify להגיש את התיקייה הזו כאתר |

## הקמה (פעם אחת, בערך 15 דקות)

### 1. למזג את הקוד לענף `main`
פאנל הניהול שומר שינויים לענף `main`, ו־Netlify מפרסם ממנו. צריך למזג את הענף שעליו נבנה האתר ל־`main` ב־GitHub.

### 2. לחבר את הריפו ל־Netlify
1. נכנסים ל־netlify.com ונרשמים עם חשבון ה־GitHub.
2. **Add new project** ← **Import an existing project** ← **GitHub** ← בוחרים את הריפו `agentai`.
3. ענף: `main`. את שאר ההגדרות לא צריך למלא, הקובץ `netlify.toml` כבר קובע אותן. לוחצים **Deploy**.
4. בהגדרות הפרויקט אפשר לשנות את השם כדי לקבל כתובת יפה, למשל `noa-ugc.netlify.app`.

### 3. לאפשר התחברות לפאנל הניהול
1. ב־GitHub: **Settings** ← **Developer settings** ← **OAuth Apps** ← **New OAuth App**.
   - **Homepage URL:** כתובת האתר מ־Netlify.
   - **Authorization callback URL:** `https://api.netlify.com/auth/done`
2. אחרי השמירה מעתיקים את ה־**Client ID**, לוחצים **Generate a new client secret** ומעתיקים גם אותו.
3. ב־Netlify, בהגדרות הפרויקט: **Access & security** ← **OAuth** ← **Install provider** ← **GitHub**, ומדביקים את שני הערכים.

### 4. לתת לה גישה
1. היא פותחת חשבון חינמי ב־github.com.
2. בריפו ב־GitHub: **Settings** ← **Collaborators** ← **Add people**, ומוסיפים את שם המשתמש שלה.
3. היא מאשרת את ההזמנה שמגיעה אליה למייל.

מכאן היא נכנסת ל־`כתובת-האתר/admin`, לוחצת "התחברות עם GitHub" ועורכת. כל פרסום מעדכן את האתר תוך דקה־שתיים.

## הערות
- **הגישה לריפו:** כ־Collaborator היא מקבלת גישה לכל הריפו `agentai`, כולל קבצים שלא קשורים לאתר. כדי להפריד, אפשר להעביר את התיקייה לריפו נפרד. אחרי המעבר מעדכנים ב־`admin/config.yml` את `repo`, את נתיבי `file:` ואת `media_folder`, ומזיזים את `netlify.toml` לשורש הריפו החדש.
- **גודל סרטונים:** כל סרטון נשמר בריפו. כדאי לדחוס כל סרטון ל־20MB לכל היותר. גם תעבורה של Netlify נספרת, וסרטונים קטנים יותר זולים יותר.
- **עריכת העיצוב:** הצבעים מוגדרים בראש `index.html`, בתוך `:root`. למשל `--paper` לרקע ו־`--copper` לצבע ההדגשה.
- **בדיקה מקומית:** `python3 -m http.server` מתוך התיקייה, ואז `http://localhost:8000`. פתיחה ישירה של הקובץ בדפדפן לא תטען את התוכן.
